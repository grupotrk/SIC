## ⚖️ **INFORMACIÓN LEGAL IMPORTANTE**

### **🔍 DECLARACIÓN PRINCIPAL**

> **Trikode Ingeniería es un Sistema de Gestión de Control Interno. Este software NO realiza facturación electrónica ni está vinculado a entes de fiscalización tributaria (ARCA/AFIP). Los datos cargados son responsabilidad exclusiva del usuario para su administración privada.**

---

## 🎯 **ALCANCE DEL SISTEMA**

### **✅ LO QUE HACE TRIKODE:**
- **Control Interno**: Gestión de stock, ventas y productos
- **Administración Privada**: Control administrativo interno
- **Reportes Internos**: Estadísticas y análisis para gestión
- **Gestión de Inventario**: Control de stock y reposición
- **Registro de Ventas**: Control de transacciones internas
- **Tickets Internos**: Comprobantes no fiscales para control

### **❌ LO QUE NO HACE TRIKODE:**
- **Facturación Electrónica**: No emite facturas fiscales
- **Vinculación AFIP**: No se conecta con entes tributarios
- **Comprobantes Fiscales**: No reemplaza facturas oficiales
- **Libros IVA**: No genera contabilidad fiscal
- **Declaraciones Juradas**: No presenta declaraciones tributarias
- **Reportes AFIP**: No envía información a organismos
